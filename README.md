# 🌍 Jornada Viagens

> Uma plataforma web moderna desenvolvida para inspirar viajantes, explorar destinos incríveis e planeizar a próxima viagem de forma simples e intuitiva.

## 🚀 Sobre o Projeto
O **Jornada Viagens** é um projeto front-end focado em criar uma experiência visual atraente e responsiva para o nicho de turismo. A aplicação foi estruturada para oferecer uma navegação fluida em diferentes dispositivos, destacando pacotes de viagens, promoções e dicas de destinos.

## ✨ Funcionalidades
- **Interface Responsiva:** Layout adaptado para computadores, tablets e telemóveis (*mobile-first*).
- **Secção de Destinos e Ofertas:** Exibição organizada de pacotes turísticos e recomendações.
- **Design Moderno:** Foco na experiência do utilizador (UX/UI) com uma identidade visual acolhedora e inspiradora.

## 🛠️ Tecnologias Utilizadas
- **HTML5** (Estruturação semântica)
- **CSS3 / Estilização** (Design responsivo e estilização visual)
